# flint
Turns data into fhir standard. Personal gooning project :)

This is a personal learning project and I am writing it by hand, not much ai and the project is slow.
The plan is simple:
- Support multiple databases: mssql, postgresql, mariadb (for now) - this is going to use a database router bridge
- The backend is going to be in C#/dotnet (.Net).
- The frontend is going to be in sveltekit.
- There is also config for loading the mapping.
